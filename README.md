
# AuthFlow – Secure Authentication System

AuthFlow is a full-stack authentication application built using React, Node.js, Express and PostgreSQL.

## Features

- User Registration
- User Login
- Password Hashing using bcrypt
- Session-based Authentication
- Protected Dashboard
- Personal User Profile
- Logout Functionality
- Responsive User Interface

## Technologies Used

- React.js
- Node.js
- Express.js
- PostgreSQL
- JavaScript
- HTML and CSS
- Axios
- bcrypt
- Express Session

## Installation

1. Clone the repository.
2. Install backend dependencies using `npm install`.
3. Navigate to the client folder and run `npm install`.
4. Configure your database credentials in `.env`.
5. Start the backend using `node app.js`.
6. Start React using `npm run dev` inside the client folder.

## Database

PostgreSQL is used to store user information. Passwords are stored as bcrypt hashes.
